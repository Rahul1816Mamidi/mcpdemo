## 2. Solution Build Plan

## Software Requirements
* **Drone Flight Control & Autonomy Stack:** Open-source ArduPilot or PX4 firmware adapted for custom RTK-GPS waypoint navigation, geofencing, and fail-safe return-to-home protocols.
* **Edge Computer Vision Pipeline:** Python/C++ pipeline utilizing OpenCV and TensorRT for real-time onboard inference (livestock tracking, weed detection, or crop stress scoring) running on Linux (Ubuntu 22.04 LTS).
* **Cloud & Ground Control Station (GCS) Web App:** React/TypeScript frontend backed by a Python FastAPI service using PostgreSQL/PostGIS to manage multi-drone fleets, mission planning, and spatial farm data visualization.

## Cloud & Infra
* **Cloud Provider:** AWS (Amazon Web Services) for scalable backend hosting, IoT Core for telemetry streaming, and S3 for storing high-resolution orthomosaic imagery and video feeds.
* **Geospatial Database Extensions:** AWS RDS PostgreSQL configured with PostGIS to efficiently query bounding boxes, geofences, and spatial agricultural layers.
* **CI/CD & Over-the-Air (OTA) Updates:** GitHub Actions paired with Docker container registries to deploy edge firmware updates and cloud microservices seamlessly.

## Third-Party APIs / API Keys Needed
* **Mapping & Tile Services:** Mapbox API or Google Maps Platform API for satellite base layers, custom polygon drawing, and mission planning UI overlays.
* **Weather & Environmental Data:** OpenWeatherMap API or NOAA/NASA POWER API to fetch real-time wind speed, precipitation, and solar radiation data prior to automated flight dispatch.
* **RTK Correction Network Services:** Swift Navigation (Piksi) or PointPerfect (u-blox) RTK-corrections API to ensure centimeter-level drone positioning accuracy during autonomous missions.

## Hardware / GPU Needs
* **Drone Airframe & Avionics:** Custom or commercial hexacopter/fixed-wing VTOL airframe equipped with Pixhawk 6X flight controllers, dual-antenna RTK-GPS, and obstacle avoidance LIDAR.
* **Payload Sensors:** Multispectral cameras (e.g., Micasense RedEdge) for crop health, or high-definition optical/thermal zoom gimbals for livestock tracking.
* **Onboard Edge Compute:** NVIDIA Jetson Orin Nano (8GB) or Xavier NX mounted on each drone to process heavy computer vision inference locally before cloud synchronization.

## Core Team Skills Needed
* **Embedded Systems / Robotics Engineer:** Expertise in ROS/ROS2, PX4/ArduPilot tuning, hardware-in-the-loop (HITL) simulation, and sensor fusion (IMU, GPS, LiDAR).
* **Computer Vision / ML Engineer:** Deep experience in PyTorch/TensorRT, model quantization, object detection (YOLOv8), and orthomosaic image stitching pipelines.
* **Full-Stack / Cloud Architect:** Proficient in React, Python (FastAPI), Docker, AWS infrastructure, and managing PostGIS spatial databases for real-time telemetry.
