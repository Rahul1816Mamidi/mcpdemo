* **AI/NLP Pipeline:** LangChain/LlamaIndex for orchestration, Whisper (via API or fine-tuned open-source) for vernacular speech-to-text (STT), and Indic Transliteration/TTS models for voice response generation.

## Cloud & Infra
* **Cloud Provider:** AWS (Mumbai region `ap-south-1`) to ensure low latency and strict adherence to India’s data residency laws.
* **Database & Storage:** PostgreSQL with TimescaleDB extension for time-series financial transaction tracking + AWS S3 for secure document/voice audio storage.
* **Orchestration & Security:** Docker & Kubernetes (EKS) for container management, backed by AWS KMS and OAuth2/JWT with end-to-end encryption for financial data.

* **Financial Data & Aggregation:** Setu or Account Aggregator (AA) framework APIs for secure, consented bank account and UPI transaction fetching.
* **Voice & Vernacular AI:** Sarvam AI APIs or OpenAI Whisper/GPT-4o APIs optimized for Indic languages (Hindi, Hinglish, and regional variants).
* **Identity & Compliance:** DigiLocker API (via signzy or similar IDfy stack) for KYC, and CIBIL/Experian API for credit score checks.
